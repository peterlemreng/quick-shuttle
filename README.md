# Quick Shuttle

Simple transport booking platform with a responsive website, Expo mobile app, and Node/Express API.

## Included
- Main town
- From / To
- Travel date and time
- Passenger details
- Automatic fare
- KSh 25 service fee per passenger
- Automatic total
- Booking confirmation
- Simple owner-ready API structure
- Advertisement-ready layout

## Run website
cd website
npm install
npm run dev

## Run backend
cd backend
npm install
npm start

## Run mobile app
cd mobile
npm install
npx expo start

Node.js 20+ recommended.
